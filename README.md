# Portuguese for Lenja

Practice Portuguese present and past tenses (presente, pretérito perfeito, pretérito imperfeito) in Brazilian or European Portuguese. Fill in the verb, check your answers, read why, and listen to the pronunciation.

It is a single static page (`index.html`) with no build step.

## Run locally

Open `index.html` in a browser.

## Deploy on GitHub Pages

The workflow in `.github/workflows/pages.yml` publishes the site automatically on every push to `main`.

1. Put `index.html`, `.nojekyll`, `README.md` and `.github/workflows/pages.yml` in the repository on the `main` branch.
2. In the repository go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **GitHub Actions**.
4. Push to `main` (or open the **Actions** tab and run **Deploy to GitHub Pages** manually). After a minute the site is live at https://bartleonid.github.io/lenja-portuguese/

## Notes

- Progress (best scores and the Brasil / Portugal choice) is stored in your browser only.
- Pronunciation uses your device's built-in voices, so it works best in Chrome, Edge or Safari.
